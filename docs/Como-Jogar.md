# Como jogar

Matterbloom é um sandbox 2D: você desenha materiais, modifica o ambiente e observa as interações. Não há fases obrigatórias.

## Primeiros passos

1. No menu inicial, escolha **Mundo natural** ou **Laboratório**.
2. Defina o cenário e clique em **Gerar novo mundo**.
3. Escolha materiais na barra inferior e desenhe com o mouse.
4. Use **Ferramentas** para aquecer, resfriar, lançar ou fixar estruturas.
5. Abra **Mundo** para controlar o clima e **Ajustes** para regular tempo, gravidade e gráficos.

## Controles

| Comando | Ação |
| --- | --- |
| Clique esquerdo / direito | Pintar / apagar |
| Roda / Ctrl + roda | Pincel / zoom |
| Arrastar com botão central | Mover câmera |
| Alt + clique | Copiar material da célula |
| B / H / C / E / I | Material / calor / frio / apagar / inspecionar |
| Espaço / N | Pausar / avançar um passo |
| Esc / Tab | Menu de pausa / ocultar interface |
| Home | Restaurar câmera |
| Ctrl+Z / Ctrl+Y | Desfazer / refazer |
| Ctrl+S / Ctrl+O | Salvar / abrir arquivo |
| F5 / F9 | Salvar / carregar slot |
| F1 / F2 | Dicas / painel científico |

Para usar **Lançador, Impulso, Ventilador, Jato, Atração ou Explosão**, segure o botão direito, arraste na direção oposta ao disparo e clique com o esquerdo. A roda ajusta a força durante a mira; Shift alterna disparo contínuo. Soltar o direito cancela a mira.

## Interface

- **Barra superior:** estado do mundo, pausa, menu e abertura dos painéis.
- **Barra inferior:** ferramentas, materiais, categorias, raio e intensidade.
- **Mundo:** bioma, clima, vento, visualizações, unidades e desafios opcionais.
- **Painel científico:** partículas, plantas, reações, FPS e tempo de processamento.
- **Ajustes:** velocidade do tempo, gravidade, frequência do motor, gráficos e iluminação.

Em **Visualizar**, escolha entre Normal, Temperatura, Umidade, Nutrientes, Saturação, Pressão, Tensões e Velocidade. As grandezas exibidas são aproximadas.
